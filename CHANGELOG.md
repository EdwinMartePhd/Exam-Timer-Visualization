# Changelog

## [1.2.0] – 2026-11-17
### Added
- Waiting screen with the exam format table (Part 1 Canvas quiz Q1–Q5, Part 2
  MATLAB Grader + Canvas Q6–Q9, 100 points) and grading rules.
- Setup field "Hide exam format info (min before start)", default 3.
- Countdown and side stats shrink while the info is shown, so everything fits on one 1080p screen.

## [1.1.0] – 2026-11-16
### Added
- Access code (password) fields for Part 1 and Part 2, with Show/Hide toggles.
- Automatic display at the bottom of the timer:
  Part 1 code from 2 min before start until 10 min after Part 1 ends;
  Part 2 code from 12 min after start until the exam ends.
- Setup preview lists when each password is shown and hidden.

## [1.0.0] – 2026-11-16
### Added
- Two-part exam timer (Part 1 = 45 min, total = 110 min) prefilled for COP2271 Exam 2.
- Large countdown for the current part, current time, total left, elapsed.
- Timeline bar, schedule table, orange/red warnings, transition and end notices.
- MATLAB-style palette, Light and Dark (projector) themes.
- Fullscreen (F), setup toggle (S), settings saved in the browser, screen wake lock.
